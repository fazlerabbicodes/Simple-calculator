# Simple Calculator UI

A clean and simple calculator user interface built using pure HTML and CSS.

## 📌 Project Overview

This project is the initial frontend layout for a web-based calculator. It focuses on structure and styling using CSS Flexbox for a clean button grid layout, along with interactive hover and active states for user feedback.

> **Note:** This repository currently contains only the **HTML** and **CSS** design. The interactive calculation logic (JavaScript) is under active development and **will be added soon**.

## 🛠️ Built With

* **HTML5** – Page structure and semantic elements.

* **CSS3** – Layout styling, custom color palette, and interactive button states.

## 🚀 Getting Started

To view this project locally:

1. **Clone the repository:**

   ```
   git clone https://github.com//calculator.git
   
   ```

2. **Navigate into the project folder:**

   ```
   cd calculator
   
   ```

3. **Open the project:**
   Simply double-click `index.html` or open it with your favorite web browser.
